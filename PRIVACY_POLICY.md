# Политика конфиденциальности GitGo

Дата вступления в силу: укажите дату публикации.

**Какие данные использует приложение**
- **Токен GitHub (PAT)** — вводится пользователем, хранится на устройстве в зашифрованном виде (Android Keystore) и отправляется только на серверы GitHub (api.github.com, github.com) для выполнения действий, которые запросил пользователь.
- **Файлы и папки** — приложение не имеет доступа ко всей памяти устройства. Доступ предоставляется только к тем файлам и папкам, которые пользователь сам выбирает в системном окне выбора. Выбранное копируется в рабочую папку репозитория внутри приложения и отправляется на GitHub только по команде пользователя.
- **Имя и email автора коммитов** — вводятся пользователем и сохраняются на устройстве, используются в коммитах.

- **Виджеты** сохраняют на устройстве последние полученные данные (график вкладов, статус CI выбранного репозитория, заголовки PR на ревью) для отображения на рабочем столе.
- **SSH-ключи** создаются на устройстве; закрытая часть хранится зашифрованной ключом Android Keystore, доступ к которому требует отпечаток пальца. Биометрические данные приложение не получает и не хранит — их обрабатывает система.
- **Доступ других приложений:** репозитории GitGo появляются в системном выборе файлов; другое приложение получает доступ только после выбора пользователем.

**Чего приложение не делает**
- Не собирает аналитику, не показывает рекламу, не передаёт данные третьим лицам, не использует сторонние SDK отслеживания.
- Не отправляет данные на серверы разработчика — их у приложения нет.

**Уведомления** используются только для показа хода передачи (объём, скорость, оставшееся время) и результата операции.

**Удаление данных**: «Настройки → Выйти и удалить токен», удаление локальных репозиториев на главном экране или удаление приложения.

**Связь**: укажите e-mail разработчика.

GitGo — неофициальный клиент и не связан с GitHub, Inc. GitHub — товарный знак GitHub, Inc.
